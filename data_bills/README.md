# data_bills — 审计凭证合成数据集

为 Qwen2.5-VL-7B LoRA 微调生成的审计凭证数据，格式与医学数据 `data/train.jsonl` 完全一致。

## 数据规模（当前 1020 条）

| 类别 | 训练 | 验证 | 说明 |
|------|:--:|:--:|------|
| 记账凭证 | 340 | 60 | 通用/收/付/转账凭证，借贷平衡 |
| 记账凭证（手写） | 102 | 18 | 楷体模拟手填 |
| 银行回单 | 187 | 33 | 14 家银行版式 |
| 差旅报销单 | 136 | 24 | 明细表 + 审批签字 |
| 差旅报销单（手写） | 102 | 18 | 楷体 + 墨迹噪声 |
| **合计** | **867** | **153** | |

## 目录

```
data_bills/
├── train.jsonl / val.jsonl
├── images/                 # 1020 张生成的凭证图片（jpg）
└── gen/                    # 合成生成器
    ├── common.py           # 字体/金额大写/随机数据/图像退化
    ├── gen_voucher.py      # 记账凭证（借=贷程序保证平衡）
    ├── gen_receipt.py      # 银行回单 / 差旅报销单
    ├── gen_handwritten.py  # 手写变体
    ├── build_jsonl.py      # 批量生成 + 转 JSONL
    └── fetch_invoices.py   # 发票公开数据筛选/脱敏（占位，待数据源）
```

## 重新生成

```bash
cd data_bills/gen
python build_jsonl.py                 # 默认数量
python build_jsonl.py --n 记账凭证=200 # 覆盖某类数量
```

## 说明

- `caption` 为审计描述（关键字段结构化），即模型要学的输出
- `instruction` 按类别定制，`train_bills.py` 逐条读取
- `category` 用于分类型评估；`label` 标注异常/正常（约 30% 为 label=1，见下文）

## 变形/损坏/不合规覆盖（审计实战）

- **图像退化**（全部样本随机 severity 0-2）：透视变形、折痕、污渍、褪色带、撕边、高斯/运动模糊、反光、旋转、噪声
- **内容异常**（约 30%，label=1，caption 标注【异常】）：
  - 记账凭证：金额大写≠数字、借贷不平衡、凭证字号缺失、未来日期、涂改痕迹
  - 银行回单：大写≠数字、流水号缺失、账号位数错误、涂改痕迹
  - 差旅报销单：合计≠明细、报销人签名缺失、报销日期早于出差、涂改痕迹

> 合成数据侧重"格式与字段结构 + 常见异常模式"；真实发票和更复杂的不合规形态
> 后续会用真实脱敏数据或公开数据集补充
